# Fachliche Abnahmetests

Alle Geldwerte sind EUR. Tests laufen gegen eine feste Regelversion; Zeit und
Zeitzone werden eingefroren.

## Pflegegrad

1. Alle Erwachsenen-Antworten 0 → 0 Punkte, kein Pflegegrad.
2. Gesamtgewicht 12,49 → kein Pflegegrad; 12,50 → PG 1; 27,00 → PG 2;
   47,50 → PG 3; 70,00 → PG 4; 90,00 → PG 5.
3. Modul 2 = 11,25 und Modul 3 = 7,5 → nur 11,25 fließen ein.
4. Rohpunkte M1=2, M2=2, M3=1, M4=3, M5=1, M6=1 →
   2,5 + max(3,75;3,75) + 10 + 5 + 3,75 = 25,00, also PG 1.
5. Alle Module maximal → 100 Punkte, PG 5.
6. Gebrauchsunfähigkeit beider Arme und Beine bei sonst 0 → PG 5.
7. Kind mit 17 vollendeten Monaten und 12,5 Punkten → PG 2; ab 18 vollendeten
   Monaten → PG 1.
8. Unbeantwortete Pflichtfrage → kein Abschluss, keine implizite Null.

## Budget und Kombination

1. PG 2, keine Sachleistung → 347 Pflegegeld.
2. PG 2, 398 Sachleistung (=50 % von 796) → 173,50 Pflegegeld.
3. PG 4, 40 % reguläre Sachleistung (=743,60) → 480 Pflegegeld.
4. PG 4, keine reguläre Sachleistung, 40 % Umwandlungsanspruch (=743,60) →
   480 Pflegegeld; eine weitere Umwandlung ist nicht möglich.
5. PG 2, 900 Ist-Sachleistung → 0 Pflegegeld, 104 Eigenanteil.
6. Entlastungsbetrag Januar bis September ohne Verbrauch → 1.179 Guthaben.
7. PG 1 → Entlastungsbetrag verfügbar, Pflegegeld und Sachleistung jeweils 0.

## Gemeinsamer Jahresbetrag / Verhinderungspflege

1. PG 3, keine Vorverbräuche → 3.539 verfügbar.
2. 1.000 Kurzzeitpflege + 700 Verhinderungspflege → 1.839 Rest.
3. Weitere Ausgabe 2.000 → 1.839 erstattungsfähig, 161 Eigenanteil, Rest 0.
4. Nahe Ersatzpflege bei PG 2: reine Vergütung maximal 694; zusätzlich 100
   Fahrtkosten → 794 erstattungsfähig, sofern Resttopf ausreichend.
5. Sonstige Ersatzpflege 800 → 800 erstattungsfähig bei ausreichendem Rest.
6. Sieben Tage tageweise Verhinderung in einem zusammenhängenden Zeitraum → fünf
   Kürzungstage; bei 347 Monats-Pflegegeld und 30-Tage-Divisor ergibt das eine
   Kürzung von 28,92 nach Rundung am Ende.
7. Sieben Einsätze mit jeweils weniger als acht Stunden → keine Kürzung und keine
   Anrechnung auf die Acht-Wochen-Grenze.

## Nachbarschaftshilfe und Dokumente

1. Zwei Stunden × 12,50 → 25,00 Leistung; Finanzierung reduziert genau einen Topf.
2. Fehlende Landesregel → Kostenaufstellung möglich, Erstattung als ungeprüft.
3. Derselbe Beleg kann nicht gleichzeitig Entlastungs- und Umwandlungsbetrag belasten.
4. Antrag ohne Versichertennummer bei dafür erforderlicher Vorlage → Vorschau zeigt
   Feldfehler, kein PDF.
5. Erzeugtes PDF erscheint mit korrektem Fall, Typ und Vorlagenversion in der Ablage.
6. Upload einer ausführbaren Datei mit umbenannter `.pdf`-Endung wird abgelehnt.
